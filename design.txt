# TrustShield — Final UI/UX Design Reference Document

# Design Vision

TrustShield should feel like:

* a modern fintech security platform
* a trusted banking protection layer
* calm and professional
* secure but not aggressive
* intelligent but lightweight

The UI must communicate:

```plaintext
Confidence
Security
Trust
Protection
Financial Safety
```

NOT:

* hacker aesthetics
* neon cybersecurity visuals
* overwhelming enterprise dashboards
* panic-driven warning screens

The design language should combine:

* fintech UX
* SBI-inspired trust colors
* modern Android Material3 patterns
* clean security signaling

---

# Core Design Philosophy

## Emotional Goal

When users open TrustShield, they should feel:

```plaintext
“I am protected.”
```

NOT:

```plaintext
“My phone is under attack.”
```

This distinction is extremely important.

| -------------- | ------- | -------------- |

# Recommended Usage Rules

## Use these as dominant colors:

* #292075
* #9A3E76
* #D54B34

## Use these sparingly:

* #00B5EF
* #F5A623

Too much cyan or amber weakens the premium fintech feel.

# Typography Scale

| Element        | Size    | Weight   |
| -------------- | ------- | -------- |
| Display        | 28px    | Bold     |
| Section Header | 20px    | SemiBold |
| Card Header    | 16px    | Medium   |
| Body           | 15–16px | Regular  |
| Caption        | 12px    | Regular  |
| Button Text    | 15px    | Bold     |

---

# Typography Guidelines

* prioritize readability
* avoid thin fonts
* use strong hierarchy
* security explanations must be easily readable

---

# Layout System

## Grid

```plaintext
4-column mobile grid
20px side margins
16px gutters
```

---

# Spacing System

Strict 8pt spacing system:

```plaintext
8px
16px
24px
32px
```

Never use random spacing values.

---

# Card Styling

| Property | Value                         |
| -------- | ----------------------------- |

| Shadow   | 0px 4px 12px rgba(0,0,0,0.05) |

* elevated
* soft
* trustworthy
* modern

# Motion Guidelines

## Use:

* subtle fade animations
* slide-up transitions
* soft loading animations
* smooth progress indicators

* aggressive flashing

* excessive motion
* hacker animations

* flashing alerts
* giant danger text
