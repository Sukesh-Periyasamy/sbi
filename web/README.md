# 💻 AnteClick React Marketing Website & Dashboard

React 19 Vite application providing the main landing page, product documentation, interactive SDK integrator info, and the threat analytics explorer dashboard.

## 🚀 Key Pages

* **Landing page:** Features on banking security and phishing statistics.
* **Threat Intelligence Dashboard:** Graph interfaces and live tables displaying the threat pipeline, campaigns, performance, and whitelists.
* **SDK Integration:** Documentation and interactive code snippets explaining how banking clients integrate native risk checks.

## ⚙️ Development

```bash
cd web
npm install
npm run dev
```

* **Build Production Bundle:** `npm run build`
* **Vercel Deployments:** Configured using `vercel.json` at root.
